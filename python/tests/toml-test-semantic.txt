# Tests from the standard TOML suite that the ryspec grammar accepts.
#
# Each one is invalid TOML for a reason no context-free grammar can see:
# every file here parses cleanly and is the loader's to reject. A file
# that is invalid for a reason the grammar CAN see does not belong here --
# fix the grammar instead. tests/test_toml_conformance.py holds this list
# to the suite in both directions, so a grammar that starts rejecting one
# of these fails until the entry is removed.
